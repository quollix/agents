# Agents

Shared agent instructions and coding conventions for the Quollix project.

This repository contains:

1. **Agent instructions**: workspace-wide change-control and safety guidance in `codex/AGENTS.md`.
2. **Workspace skill**: reusable coding conventions for Codex in `codex/workspace/`, including references for architecture, errors, testing, generated files, CLI patterns, and taskrunner usage.
